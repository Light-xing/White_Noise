# 文档说明

本文档围绕 WhiteNoise 白噪音专注助手第一版，整理产品需求、功能范围、界面与数据设计、验收标准以及项目进度安排。第一阶段的目标是在不使用后端、数据库和用户登录的前提下，完成一个适用于手机端的单页面白噪音应用。

核心交付内容包括三种环境声音切换、播放与暂停、音量调节和定时关闭；项目计划以约四周为周期，按需求与静态页面、Vue 交互、音量与定时、测试与优化四个阶段推进。

## 一、项目概述

### 1.1 项目名称

**WhiteNoise——白噪音专注助手**

### 1.2 项目目标

使用课程中涉及的基础前端知识完成一个适用于手机端的简单白噪音应用。

第一版主要使用以下技术：

- HTML5
- CSS3
- JavaScript
- Vue.js

第一版不使用后端、数据库、用户登录等复杂功能。

项目主要实现：

- 环境声音选择
- 声音播放
- 声音暂停
- 音量调节
- 定时关闭

## 二、需求分析

### 2.1 用户需求

本项目主要面向学习、阅读、专注和休息场景。

用户打开应用后，可以选择喜欢的环境声音并进行播放，同时可以调整音量和设置定时关闭时间。

基本操作流程如下：

打开应用  
↓  
选择环境声音  
↓  
点击播放  
↓  
调整音量  
↓  
设置定时关闭  
↓  
时间结束后自动停止播放

## 三、功能需求

### 3.1 环境声音选择

第一版提供三种环境声音：

- 白噪音
- 雨声
- 海浪声

用户点击对应的声音选项后，将当前播放声音切换为所选择的声音。

例如：

○ 白噪音  
● 雨声  
○ 海浪

Vue 中可以使用变量保存当前选择：

currentSound

例如：

currentSound = "rain"

### 3.2 播放功能

用户点击"播放"按钮后，开始播放当前选择的环境声音。

界面示例：

▶ 播放

播放后按钮状态变为：

⏸ 暂停

使用 Vue 数据记录播放状态：

isPlaying

状态变化：

false  
↓  
点击播放  
↓  
true

### 3.3 暂停功能

当声音正在播放时，用户点击"暂停"按钮，可以停止当前播放。

状态变化：

true  
↓  
点击暂停  
↓  
false

### 3.4 音量调节

用户可以通过滑动条调整播放音量。

界面示例：

🔈 ───────●──── 🔊

音量范围：

0% ～ 100%

可以使用 HTML5：

&lt;input type="range"&gt;

实现滑动控制。

Vue 中使用变量保存音量：

volume

### 3.5 定时关闭

用户可以设置声音播放时间。

第一版提供：

- 15 分钟
- 30 分钟
- 60 分钟

例如：

15分钟 30分钟 60分钟

用户选择之后开始倒计时：

29:59  
29:58  
29:57  
...  
00:00

时间到达 00:00 后自动停止声音播放。

可以使用 JavaScript：

setInterval()

或：

setTimeout()

实现定时功能。

## 五、移动端适配需求

由于项目主要面向手机端，因此页面需要满足以下要求：

- 支持手机竖屏显示
- 页面宽度适应手机屏幕
- 不出现横向滚动条
- 按钮尺寸适合手机点击
- 字体清晰
- 音量滑动条方便操作
- 页面结构简洁
- 不需要放大页面即可操作

主要使用 CSS3 完成移动端界面设计。
