# WhiteNoise 白噪音专注助手

手机端单页白噪音应用，按需求文档 V1.0 的范围实现：白噪音 / 雨声 / 海浪声切换、播放暂停、音量调节、15 / 30 / 60 分钟定时关闭。纯静态页面，不需要后端，也没有构建步骤。V1.1 加了动态背景、结束前淡出、锁屏控制和上次状态记忆；V1.2 加了本地音频上传和像素方块可视化。

双击 `index.html` 即可打开。Vue 3 放在 `lib/` 里，断网也能用。

## 交互约定

- 内置三种声音共用一个 audio 元素，自定义音频使用独立元素；同一时刻只有一个声音在播放。切换声音时先停止当前声音，再替换音源，按钮回到“播放”。
- 暂停会同时取消当前定时，重新播放后需要再选一次档位。
- 未播放时选档位只是预设定时：倒计时停在整段时长不动，按播放后才开始递减。
- 再次点击当前档位可以取消定时（未开始或进行中都可以）；倒计时结束会停止播放、清空档位，音量保持不变。
- 倒计时过程中切换声音，计时继续，不会重置。
- 第四个声音是自定义：点“环境声音”右侧的上传按钮选择小于 10MB 的音频文件，上传后自动切到自定义并停止当前播放，点播放开始。
- 自定义音频只在当前页面会话里有效，刷新后需要重新上传；文件不会上传到服务器。
- 音量滑动条取值 0–100，内置声音按 `volume / 100` 写入 audio 元素，自定义音频写入 GainNode。V1.0 不显示百分比数值。

## V1.1 拓展

- 动态背景：`js/scene.js` 用 canvas 画三种场景——白噪音漂浮颗粒、雨丝、海浪，随播放状态和音量变化，切声音时交叉淡化。页面切到后台停止绘制，系统开启“减少动态效果”时只画一帧静态图。
- 结束前淡出：定时最后 30 秒把音量平滑降到 0，不是到点硬停。暂停、切声音或取消定时会恢复音量，下一次播放不受影响。
- 锁屏控制：接入 Media Session，锁屏和通知栏显示当前声音，可以直接播放 / 暂停；封面在运行时用 canvas 生成，不额外加图片文件。
- 记住上次状态：`localStorage` 保存声音和音量，刷新后恢复，但不自动播放。存储不可用时静默回到默认值。

## V1.2 自定义音频

- 入口是“环境声音”右侧的上传按钮。上传成功后第四个“自定义”卡片启用并自动选中，播放区显示去掉扩展名的文件名。
- 自定义音频单独使用一个 audio 元素，经过 `GainNode` 和 `AnalyserNode`：音量和淡出走增益节点，canvas 背景按实时频谱画 4–5px 的像素方块。
- 频段取 35Hz–12kHz 对数分布，右端高频做 1.5 倍补偿；柱体从下到上深青→浅青渐变，列间距 2–3px。
- 高度用软膝压缩（阈值 0.55、软上限 0.9）：正常响度基本线性，响度越大越接近上限但最高约 74%；顶部另留 2 行，任何响度都不会碰到高度线。配色整体压暗。
- 内置三种声音继续走原来的 audio 元素和 `audio.volume`，Web Audio 只接自定义那一路，不会让内置声音变哑。
- 无法解析的上传文件会弹出“音频无法解析”对话框，关闭后可重新选择。
- 常见 mp3 / wav / m4a / ogg 由浏览器解码；超过 10MB 或非音频文件会在原错误提示位置拒绝。

## 已知限制

- iOS Safari 的 `audio.volume` 只读：内置三种声音的音量条和淡出在 iPhone 上无效；自定义音频走 GainNode，不受这个限制。
- 自定义音频只保留在当前页面会话，刷新后需要重新上传。
- Web Audio 初始化失败时自定义音频仍能播放，但背景只显示空闲的暗色方块。
- 自定义音频的实时可视化只在 Chrome 验证过，iOS / 真机上的 Web Audio 表现未确认。
- 锁屏控制在 Android Chrome 上效果最好，iOS 对 Media Session 的支持有限。
- 部分浏览器在 `file://` 下禁用 `localStorage`，此时不会记忆声音和音量，功能本身不受影响。
